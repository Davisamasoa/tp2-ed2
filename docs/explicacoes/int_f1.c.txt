= Implementação do **método 2**: intercalação balanceada de vários caminhos com f+1 fitas (f = 19). Fase 1: seleção por substituição com heap de 19 registros, distribuindo os blocos nas fitas 0 a 18. Fase 2: cada passada intercala o i-ésimo bloco de cada uma das 19 fitas num único bloco gravado na fita 19 (a única de saída). Se a fita de saída ficou com mais de um bloco, os blocos são **redistribuídos** de volta nas 19 fitas e começa outra passada. O último registro de cada bloco é marcado (`marcado = 1`) para que o fim do bloco seja conhecido sem comparar notas.
